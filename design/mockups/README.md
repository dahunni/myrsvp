# Mockups

Approved screens for the Qin F22 Pro, as Design Component HTML (px at 640 × 960; divide by 2 for dp).
They reference a canvas runtime (`support.js`) that isn't included, so read the markup rather than
opening them in a browser. Live canvas: https://claude.ai/artifact/X9DpZKhcrxuJS6t6MEmAVz

- `Main.dc.html` — Reader, dark (default theme)
- `ReaderLight.dc.html` — Reader, light (Spritz style)
- `Paused.dc.html` — Paused with sentence context
- `Library.dc.html`, `Menu.dc.html`, `Settings.dc.html` — D-pad lists, focused row = accent outline

`docs/DESIGN.md` is the source of truth where the two differ.
